1 Este app não tem "conta"

O Fiorote Finanças não pede cadastro, e-mail ou senha. Não existe um servidor com uma conta sua pra excluir.

Todos os seus lançamentos (despesas, receitas, cartões) ficam guardados apenas no seu aparelho. "Excluir a conta" nesse app equivale a apagar os dados guardados localmente — veja como abaixo.

2 Apagar todos os dados do aparelho

Como os dados vivem só no seu celular, qualquer uma das opções abaixo apaga tudo permanentemente:

  1. Desinstalar o app — remove instantaneamente todo o banco de dados local (despesas, receitas, cartões, preferências)
  2. Android → Configurações → Apps → Fiorote Finanças → Armazenamento → Limpar dados — apaga tudo sem precisar desinstalar

Se quiser guardar uma cópia antes de apagar, use Configurações → Exportar backup (arquivo) dentro do app pra salvar um arquivo com todos os seus dados antes de remover.

3 Se você conectou o Google Drive

Conectar o Drive é opcional, usado só pra backup. Se você ativou essa opção:

  1. Desconectar no app — em Configurações → Backup → Google Drive → toque no botão de desconectar. Isso para o app de acessar sua conta, mas não apaga o arquivo já enviado.
  2. Apagar o arquivo de backup no Drive — acesse drive.google.com, procure por fiorote-backup.json e exclua o arquivo.
  3. Revogar o acesso do app à sua conta Google (opcional, remove a permissão por completo) — acesse myaccount.google.com/permissions, encontre "Fiorote Finanças" na lista e remova o acesso.

4 Assinatura ativa

Se você tem a assinatura "sem anúncios" ativa, ela é gerenciada pelo Google Play, não pelo app. Pra cancelar, acesse play.google.com/store/account/subscriptions — desinstalar ou apagar os dados do app não cancela a cobrança automaticamente.
